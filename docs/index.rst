Pareto/NBD Extension Documentation
=====================================

Welcome to the documentation for **Non-contractual churn with MCMC: are Pareto/NBD purchase forecasts calibrated?**.

This repository provides a complete Python framework for probabilistic evaluation of Buy-Till-You-Die (BTYD) models using proper scoring rules (CRPS, Log Score), calibration diagnostics (randomized PIT, coverage), parameter estimation (MCMC Gibbs sampler, robust MLE), Pareto/GGG inter-purchase regularity extensions, purchase timing forecasting ($t_{x+1}$), and probabilistic Customer Lifetime Value (CLV) estimation.
